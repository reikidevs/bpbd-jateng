# BPBD Provinsi Jawa Tengah - Web Portal Prototype

Portal Informasi Kebencanaan dan Tanggap Darurat Badan Penanggulangan Bencana Daerah (BPBD) Provinsi Jawa Tengah.

## Live Demo
Akses live demo prototype portal melalui GitHub Pages:
[https://reikidevs.github.io/bpbd-jateng/](https://reikidevs.github.io/bpbd-jateng/)

## Fitur Utama
- Portal Informasi Bencana Terkini & Peringatan Dini Wilayah Jawa Tengah.
- Sistem Informasi Logistik & Penanganan Bencana Darurat.
- Integrasi Kontak Cepat & Pelayanan Masyarakat Berbasis Multi-kanal.
- Desain antarmuka responsif ramah perangkat mobile & desktop.
